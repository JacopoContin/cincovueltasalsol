# Cinco Vueltas al Sol

Sitio web de una sola página para la comunidad de madres y padres de niños con necesidades especiales.

- `index.html` — página completa (HTML + CSS + JS, sin dependencias de build)
- `assets/logo.png`, `assets/favicon.png` — logo

Para verla, abre `index.html` en el navegador o publica la carpeta en GitHub Pages / Netlify / Vercel.

Pendiente de personalizar: email de contacto (`hola@cincovueltasalsol.com`), enlaces de redes sociales y testimonios reales.
