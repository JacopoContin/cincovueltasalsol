# Cinco Vueltas al Sol

Sitio web de una sola página de Cinco Vueltas al Sol: plataforma en vídeo y podcast sobre maternidad y paternidad atípica, por María Gay Rosell (@cincovueltasalsol).

- `index.html` — página completa (HTML + CSS + JS, sin dependencias de build)
- `assets/logo.png`, `assets/favicon.png` — logo

Para verla, abre `index.html` en el navegador o publica la carpeta en GitHub Pages / Netlify / Vercel.

Pendiente de personalizar: email de contacto (`hola@cincovueltasalsol.com`) y enlaces de YouTube/Spotify cuando existan.
